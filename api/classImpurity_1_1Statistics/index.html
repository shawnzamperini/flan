    Detailed Description

    Class to hold all the vectors related to tracking the statistics of an impurity transport simulation. Each array is indexed by (time frame, x cell, y cell, z cell).

    Converts the summed charge in each cell and time frame into the weighted average charge.

    Each sum is divided by the weight in the cell. Cells with no counts are set to 0.

    function calc_density

    void Impurity::Statistics::calc_density (
    const Background::Background & bkg,
    const int tot_imp_num,
    const double imp_source_scale_fact=1.0
)

    Calculates the impurity density in each cell and time frame from the weights.

    The weights were accumulated as weight * dt, so they are already in number of particles, and the particle weights were normalized by the number of particles when each particle was created. The density is then just the weight divided by the cell volume in physical space, J * dx * dy * dz. The density array is allocated here.

    Parameters:

    • bkg Background plasma, used for the grid and Jacobian.
    • tot_imp_num Total number of impurities followed. Currently unused.
    • imp_source_scale_fact Number of particles/s a single particle represents. Currently unused.

    function operator+

    Statistics Impurity::Statistics::operator+ (
    const Statistics & other
) const

    Adds two Statistics objects together.

    The counts, weights, charge, s and velocity arrays are summed. Right now only a single particle track is recorded, so the track is copied from other instead of combined.

    Parameters:

    • other Statistics object to add to this one. Must have the same dimensions.

    Returns:

    New Statistics object holding the sums.

    function pack

    void Impurity::Statistics::pack (
    std::vector< double > & buf
) const

    Packs all the arrays into a single buffer that can be sent across MPI processes.

    The arrays are appended in the order counts, weights, charge, s, vX, vY, vZ, vx, vy, vz. The counts are converted to double. The track and density are not included.

    Parameters:

    • buf Buffer to fill. Any previous contents are cleared.

    function to_device

    ImpurityStats::StatisticsDevice Impurity::Statistics::to_device (
    int device_id
)

    Allocates GPU memory for the statistics arrays and copies them to the device.

    The counts, weights, velocity, charge and s arrays are copied. The track and density are not. If GPU support was not compiled in, an empty StatisticsDevice is returned.

    Parameters:

    • device_id ID of the GPU to allocate the memory on.

    Returns:

    StatisticsDevice struct holding the device pointers. The memory must be released with free_stats.
