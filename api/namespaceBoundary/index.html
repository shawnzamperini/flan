    function absorbing_bc

    int Boundary::absorbing_bc (
    double a,
    double bound,
    bool max_bound,
    double buffer
)

    Checks if a value is outside an absorbing boundary.

    max_bound = true means bound is a maximum and the check is a + buffer >= bound. max_bound = false means bound is a minimum and the check is a - buffer <= bound. The buffer makes the boundary trigger sooner, since the plasma can behave oddly right at the boundaries. Written without branches so it is SIMD friendly.

    Parameters:

    • a Value to check (e.g., the particle's x coordinate).
    • bound Boundary value.
    • max_bound If true, bound is a maximum. Otherwise it is a minimum.
    • buffer Distance the boundary is moved inward. Defaults to 0.

    Returns:

    1 if the particle is outside the boundary (dead), else 0.

    function check_bounds_cpu

    void Boundary::check_bounds_cpu (
    Slots::Slots & slots,
    const Background::Background & bkg,
    const Options::Options & opts,
    std::vector< pcg32 > & rngs
)

    Checks every alive particle against the time and spatial boundaries and applies the boundary conditions (CPU implementation).

    The boundaries are checked in the order t, then min/max x, y and z. Each boundary type is an integer from the *bound_type options: 0 = absorbing, 1 = periodic and 2 = core (x, y and z only). An absorbing boundary sets the slot's state and skips the remaining checks as soon as the particle is dead. For a core boundary in x, y and z are randomized, in y, z and x are randomized, and in z, x and y are randomized. The spatial buffers are the imp_*bound_buffer options, and the time boundary has no buffer. The loop over particles is parallelized with OpenMP.

    Parameters:

    • slots Particle slots. The state, t and positions are updated in place.
    • bkg Background plasma, used for the simulation bounds.
    • opts Simulation options, used for the boundary types and buffers.
    • rngs Random number generators, one per OpenMP thread, used by the core boundary.

    Launches check_bounds_kernel to apply the time and spatial boundary conditions to every particle on the GPU.

    Uses blocks of 256 threads, one thread per slot. The launch is asynchronous, except in DEBUG builds, where it waits for the kernel to finish and prints any error.

    void Boundary::check_bounds_kernel (

    const double imp_xbound_buffer,
    const double imp_ybound_buffer,
    const double imp_zbound_buffer,
    const double lcfs_x,
    pcg32 * rngs_d
)

    Kernel that checks each particle against the time and spatial boundaries and applies the boundary conditions.

    One thread handles one slot, and dead particles are skipped. The boundaries are checked in the order t, then min/max x, y and z. Each boundary type is an integer: 0 = absorbing, 1 = periodic and 2 = core (x, y and z only). An absorbing boundary sets the slot's state and returns as soon as the particle is dead. For a core boundary in x, y and z are randomized, in y, z and x are randomized, and in z, x and y are randomized.

    Parameters:

    • slots_d Particle slots on the device. The state, t and positions are updated in place.
    • bkg_d Background plasma on the device. Currently unused.
    • tbound_type_int Type of the maximum time boundary (0 or 1).
    • min_xbound_type_int Type of the minimum x boundary.
    • max_xbound_type_int Type of the maximum x boundary.
    • min_ybound_type_int Type of the minimum y boundary.
    • max_ybound_type_int Type of the maximum y boundary.
    • min_zbound_type_int Type of the minimum z boundary.
    • max_zbound_type_int Type of the maximum z boundary.
    • imp_xbound_buffer Buffer on the x boundaries.
    • imp_ybound_buffer Buffer on the y boundaries.
    • imp_zbound_buffer Buffer on the z boundaries.
    • lcfs_x x coordinate of the last closed flux surface. Currently unused.
    • rngs_d Random number generators on the device, one per slot.

    function core_bc

    void Boundary::core_bc (
    double & a,
    double & b,
    double & c,
    double a_min,
    double a_max,
    double a_buffer,
    double b_min,
    double b_max,
    double b_buffer,
    double c_min,
    double c_max,
    double c_buffer,
    bool max_bound,
    pcg32 & rng
)

    Applies a core boundary condition.

    The coordinate being checked is a, and b and c are the other two coordinates. If a is past the boundary (moved inward by a_buffer), a is put back on the buffered boundary, and b and c are moved to uniformly random values between their buffered minimums and maximums. This is like the particle entering the core and popping back out somewhere else along the core boundary. A residence time could be added if it was useful.

    Parameters:

    • a Coordinate checked against the boundary.
    • b First of the other two coordinates.
    • c Second of the other two coordinates.
    • a_min Minimum of a.
    • a_max Maximum of a.
    • a_buffer Distance the a boundary is moved inward.
    • b_min Minimum of b.
    • b_max Maximum of b.
    • b_buffer Buffer on each side of the b range.
    • c_min Minimum of c.
    • c_max Maximum of c.
    • c_buffer Buffer on each side of the c range.
    • max_bound If true, check the a_max side. Otherwise check the a_min side.
    • rng Random number generator for this thread.

    function periodic_bc

    double Boundary::periodic_bc (
    double a,
    double amin,
    double amax
)

    Applies a periodic boundary condition.

    A periodic boundary never kills a particle. A value above amax has the domain length (amax - amin) subtracted, and a value below amin has it added. Only a single wrap is done, so a particle is assumed to move less than one domain length per time step. Written without branches so it is SIMD friendly.

    Parameters:

    • a Value to check (e.g., the particle's y coordinate).
    • amin Minimum of the domain.
    • amax Maximum of the domain.

    Returns:

    The wrapped value, or a unchanged if it is inside the domain.
