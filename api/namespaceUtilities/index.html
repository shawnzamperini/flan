    function bilinear_interp

    template<typename T>
inline T Utilities::bilinear_interp (
    const T *__restrict__ table,
    const T *__restrict__ x_grid,
    int nx,
    const T *__restrict__ y_grid,
    int ny,
    T x,
    T y
)

    Performs bilinear interpolation on a flattened two-dimensional lookup table stored in device memory.

    The function locates the grid cell that contains the point (x, y), computes the interpolation weights in each dimension, and returns the bilinearly interpolated value. Interpolation weights are clamped to the range [0, 1] to prevent extrapolation beyond the boundaries of the tabulated data.

    The table is assumed to be stored in row-major order with dimensions nx × ny, where the flattened index corresponding to (ix, iy) is ix * ny + iy.

    Template parameters:

    • T Floating-point data type used for the table and coordinate arrays.

    Parameters:

    • table Flattened two-dimensional lookup table of size nx * ny.
    • x_grid Monotonically increasing x-coordinate array of length nx.
    • nx Number of x-grid points.
    • y_grid Monotonically increasing y-coordinate array of length ny.
    • ny Number of y-grid points.
    • x X-coordinate at which to evaluate the table.
    • y Y-coordinate at which to evaluate the table.

    Returns:

    Bilinearly interpolated value at (x, y).

    Performs bilinear interpolation within a rectangular region in two-dimensional (x, y) space.

    The function interpolates a value at the coordinates (x, y) using values defined at the corners of a rectangle bounded by (x0, y0) and (x1, y1).

    Parameters:

    • x0 Lower x-coordinate of the rectangle.
    • y0 Lower y-coordinate of the rectangle.
    • z0 Value at the lower corner.
    • x1 Upper x-coordinate of the rectangle.
    • y1 Upper y-coordinate of the rectangle.
    • z1 Value at the upper corner.
    • x X-coordinate at which to evaluate the interpolated value.
    • y Y-coordinate at which to evaluate the interpolated value.

    Returns:

    Bilinearly interpolated value at (x, y). Performs bilinear interpolation within a rectangular region in two-dimensional (x, y) space.

    The rectangle is defined by the coordinates (x0, y0) and (x1, y1), with values specified at each of the four corners. Interpolation is performed first along the x direction and then along the y direction to obtain the value at (x, y).

    Corner indexing follows the usual convention:

    z00 : (x0, y0) z10 : (x1, y0) z01 : (x0, y1) z11 : (x1, y1)

    Parameters:

    • x0 Lower x-coordinate of the rectangle.
    • y0 Lower y-coordinate of the rectangle.
    • x1 Upper x-coordinate of the rectangle.
    • y1 Upper y-coordinate of the rectangle.
    • z00 Value at (x0, y0).
    • z10 Value at (x1, y0).
    • z01 Value at (x0, y1).
    • z11 Value at (x1, y1).
    • x X-coordinate at which to evaluate the interpolated value.
    • y Y-coordinate at which to evaluate the interpolated value.

    Returns:

    Bilinearly interpolated value at (x, y).

    function bracket_indices

    std::pair< int, int > Utilities::bracket_indices (
    const std::vector< double > & x,
    double x0
)

    Finds the indices of the two grid points that bracket a specified coordinate value.

    For values within the coordinate range, the returned indices correspond to the nearest lower and upper grid points that surround x0. For values outside the coordinate range, the first or last valid interval is returned so that interpolation can proceed without accessing elements beyond the array bounds.

    The input coordinate array is assumed to be sorted in ascending order.

    Parameters:

    • x Sorted coordinate array.
    • x0 Coordinate value for which bracketing indices are sought.

    Returns:

    Pair containing the lower and upper bracketing indices {lo, hi}.

    function get_neighbor_index

    template<typename T>
int Utilities::get_neighbor_index (
    const double val,
    const std::vector< T > & cell_centers,
    const int idx
)

    Returns the index of the nearest neighboring cell center to a specified cell center index.

    The neighbor is selected based on which side of the cell center the value lies. If the value is greater than the cell center, the neighboring index to the right is returned. If the value is less than or equal to the cell center, the neighboring index to the left is returned.

    At the edges of the grid, where only one neighboring cell exists, that neighbor is returned regardless of which side of the cell center the value lies on.

    Template parameters:

    • T Data type of the cell center coordinates.

    Parameters:

    • val Coordinate value of interest.
    • cell_centers Array of cell center coordinates.
    • idx Index of the reference cell center.

    Returns:

    Index of the neighboring cell center closest to the side of the cell containing val.

    function interp_vec4d

    template<typename T>
double Utilities::interp_vec4d (
    const Vectors::Vector4D < T > & vec4d,
    const std::vector< double > t,
    const std::vector< double > x,
    const std::vector< double > y,
    const std::vector< double > z,
    const double t0,
    const double x0,
    const double y0,
    const double z0
)

    Interpolates a value from a 4D field defined on a structured (t, x, y, z) grid.

    Trilinear interpolation is performed in the spatial dimensions (x, y, z) at the two time slices that bracket t0, followed by linear interpolation in time. Spatial coordinates are clamped to the grid boundaries to prevent extrapolation beyond the edge cell-center values.

    Template parameters:

    • T Data type stored in the 4D field.

    Parameters:

    • vec4d 4D field to sample.
    • t Time coordinate array.
    • x X coordinate array.
    • y Y coordinate array.
    • z Z coordinate array.
    • t0 Time coordinate at which to evaluate the field.
    • x0 X coordinate at which to evaluate the field.
    • y0 Y coordinate at which to evaluate the field.
    • z0 Z coordinate at which to evaluate the field.

    Returns:

    Interpolated field value.

    function mpi_broadcast_vector

    template<typename T>
void Utilities::mpi_broadcast_vector (
    std::vector< T > & v,
    int root,
    MPI_Comm comm
)

    Broadcasts a vector from a root MPI rank to all other ranks in the communicator.

    The root rank provides the vector contents and size. The vector size is first broadcast to all ranks, allowing non-root ranks to resize their local vectors before the vector data itself is broadcast.

    The element type T must have a corresponding MPI datatype defined through mpi_type<T>::type.

    Template parameters:

    • T Data type stored in the vector.

    Parameters:

    • v Vector to broadcast. On the root rank, contains the source data. On all other ranks, receives the broadcasted data.
    • root Rank that owns the source vector.
    • comm MPI communicator over which the broadcast is performed.

    function split_str_at_spaces

    std::vector< std::string > Utilities::split_str_at_spaces (
    std::string & str
)

    Splits a string into whitespace-delimited tokens.

    Consecutive whitespace characters are treated as a single delimiter, and leading or trailing whitespace is ignored. The resulting vector contains each extracted token in the order it appears in the input string.

    Internally, the string is parsed using a std::istringstream and repeated applications of the stream extraction operator.

    Parameters:

    • str String to split.

    Returns:

    Vector containing the whitespace-delimited tokens extracted from the input string.

    function trilinear_interpolate

    inline double Utilities::trilinear_interpolate (
    const double x0,
    const double y0,
    const double z0,
    const double x1,
    const double y1,
    const double z1,
    const double v000,
    const double v100,
    const double v010,
    const double v110,
    const double v001,
    const double v101,
    const double v011,
    const double v111,
    const double x,
    const double y,
    const double z
)

    Performs trilinear interpolation within a rectangular cell in (x, y, z) space.

    The cell is defined by the coordinates (x0, y0, z0) and (x1, y1, z1), with values specified at each of the eight cell corners. Interpolation weights are clamped to the range [0, 1] to prevent extrapolation beyond the cell boundaries. As a result, points outside the cell return the value on the nearest cell face, edge, or corner.

    Corner indexing follows the usual convention:

    v000 : (x0, y0, z0) v100 : (x1, y0, z0) v010 : (x0, y1, z0) v110 : (x1, y1, z0) v001 : (x0, y0, z1) v101 : (x1, y0, z1) v011 : (x0, y1, z1) v111 : (x1, y1, z1)

    Parameters:

    • x0 Lower x-coordinate of the cell.
    • y0 Lower y-coordinate of the cell.
    • z0 Lower z-coordinate of the cell.
    • x1 Upper x-coordinate of the cell.
    • y1 Upper y-coordinate of the cell.
    • z1 Upper z-coordinate of the cell.
    • v000 Field value at (x0, y0, z0).
    • v100 Field value at (x1, y0, z0).
    • v010 Field value at (x0, y1, z0).
    • v110 Field value at (x1, y1, z0).
    • v001 Field value at (x0, y0, z1).
    • v101 Field value at (x1, y0, z1).
    • v011 Field value at (x0, y1, z1).
    • v111 Field value at (x1, y1, z1).
    • x X-coordinate at which to evaluate the field.
    • y Y-coordinate at which to evaluate the field.
    • z Z-coordinate at which to evaluate the field.

    Returns:

    Interpolated field value.
