    function all_dead_wrapper

    bool ImpurityTransport::all_dead_wrapper (
    Slots::Slots & slots,
    Slots::SlotsDevice & slots_d,
    const Options::Options & opts,
    int rem_parts
)

    Checks whether the simulation is finished, choosing the CPU or GPU implementation.

    The simulation is finished when no particles are waiting to be launched and every particle in slots is dead. If rem_parts is positive, false is returned without checking slots. If GPU acceleration is on (use_gpu), Slots::all_dead_gpu is called, which copies data from the GPU and so implicitly synchronizes it. The GPU branch only exists in CUDA builds.

    Parameters:

    • slots Host-side particle slots (used on the CPU path).
    • slots_d Device-side particle slots (used on the GPU path).
    • opts Simulation options, used to check whether the GPU is on.
    • rem_parts Number of particles still waiting to be launched.

    Returns:

    True if no particles remain to be launched and every slot is dead, false otherwise.

    const Background::Background & bkg,
    const Background::BackgroundDevice & bkg_d,
    const Options::Options & opts,

)

    Updates particle velocities with the Boris algorithm, choosing the CPU or GPU implementation.

    If GPU acceleration is on (use_gpu), Boris::update_velocity_gpu is called. Otherwise Boris::update_velocity_cpu is called. The GPU branch only exists in CUDA builds. A negative dt pushes the velocities backward in time, which main_loop uses to offset the starting velocities by half a time step.

    Parameters:

    • slots Host-side particle slots (used on the CPU path).
    • slots_d Device-side particle slots (used on the GPU path).
    • bkg Host-side background plasma (used on the CPU path).
    • bkg_d Device-side background plasma (used on the GPU path).
    • opts Simulation options.
    • dt Time step to advance the velocities by (s).

    function collision_cpu

    void ImpurityTransport::collision_cpu (
    Slots::Slots & slots,
    const Background::Background & bkg,
    const double dt,
    const Options::Options & opts,
    Impurity::Statistics & imp_stats,
    std::vector< pcg32 > & rngs
)

    Applies Coulomb collisions with the background ions and electrons to every particle in slots (CPU implementation).

    Particle velocities are updated in place with the Nanbu collision model. Collisions with the background ions are always applied. Collisions with the electrons are applied afterwards, except for the friction_force test case, which only considers ion collisions so the result can be compared against the expected flow.

    Parameters:

    • slots Particle slots whose velocities are updated.
    • bkg Background plasma that provides the ion and electron properties.
    • dt Time step (s).
    • opts Simulation options, used to check the test_opt option.
    • imp_stats Impurity statistics passed through to the collision model.
    • rngs Random number generators, one per OpenMP thread.

    function find_containing_cell_cpu

    void ImpurityTransport::find_containing_cell_cpu (
    Slots::Slots & slots,
    const Background::Background & bkg
)

    Finds the background time index and spatial cell indices for every particle in slots (CPU implementation).

    Time and space are handled differently. The background times are stored at "time centers" rather than on a grid, so the time index is the index of the background time nearest to the particle's time. The spatial coordinates are defined by grid edges, so each spatial index is the index of the cell that contains the particle's x, y and z coordinates. Particles outside the grid are assigned the first or last cell in that dimension.

    The indices are written back into slots with set_tidx, set_xidx, set_yidx and set_zidx. The loop over particles is parallelized with OpenMP. Every slot is updated, including slots holding dead particles.

    Parameters:

    • slots Particle slots whose positions are read and whose time and cell indices are updated.
    • bkg Background plasma that provides the time array and the x, y and z grid edges.

    function follow_impurities

    Impurity::Statistics ImpurityTransport::follow_impurities (
    Background::Background & bkg,
    Options::Options & opts,
    Timer::Timer & timer
)

    Follows every impurity particle through the background plasma and returns the accumulated statistics.

    This is the top-level driver for impurity transport. It sets up the impurity statistics arrays, loads the OpenADAS rate coefficients (one MPI rank at a time, to avoid every rank reading the same files at once) and allocates the particle slots, with min(slot_cap, imp_num) slots. All slots start dead so the first fill launches particles into them.

    On GPUs, the data is copied to each GPU, a random number generator is set up for each GPU thread, and gpu_worker runs main_loop on every GPU concurrently. The statistics and timers from each GPU are then combined and the device memory is freed. On CPUs, one random number generator is created per OpenMP thread and main_loop is called directly. If GPU acceleration was requested in a build without CUDA, it is turned off.

    If the seed option is negative, random number generators are seeded from the clock so each run is different. Otherwise the seed option is used. In both cases the MPI rank is added to the seed so each rank gets a different sequence.

    Parameters:

    • bkg Background plasma to follow the particles through.
    • opts Simulation options. use_gpu may be turned off if Flan was built without GPU support.
    • timer Timer that accumulates the time spent in each step.

    Returns:

    Impurity statistics accumulated from every particle followed on this rank.

    function main_loop

    void ImpurityTransport::main_loop (
    Slots::Slots & slots,
    Slots::SlotsDevice & slots_d,
    const Background::Background & bkg,
    const Background::BackgroundDevice & bkg_d,
    Impurity::Statistics & imp_stats,
    ImpurityStats::StatisticsDevice & imp_stats_d,
    const OpenADAS::OpenADAS & oa_ioniz,
    const OpenADAS::OpenADASDevice & oa_ioniz_d,
    const OpenADAS::OpenADAS & oa_recomb,
    const OpenADAS::OpenADASDevice & oa_recomb_d,
    Options::Options & opts,
    Options::OptionsDevice * opts_d,
    Timer::Timer & timer,
    int & ioniz_warnings,
    int & recomb_warnings,
    std::vector< pcg32 > & rngs,
    pcg32 * rngs_d,
    int & max_time_ctr
)

    Runs the main particle-following loop until every particle has been launched and followed until it dies.

    The imp_num particles are split evenly between the MPI ranks, with the remainder going to the last rank. When running on GPUs, each rank's share is split again between its GPUs, with the remainder going to device 0. The slots are then filled, and the starting velocities are pushed back half a time step as the Boris algorithm requires. Each iteration of the loop then:

    • Updates charge states from ionization/recombination (if imp_iz_recomb is on).
    • Applies collisions (if imp_collisions is on).
    • Updates velocities with the Boris algorithm.
    • Advances particle positions.
    • Checks the time and spatial bounds.
    • Replaces dead particles with new ones.
    • Finds the containing cell of each particle.
    • Records statistics.

    Each step is timed with a scoped timer. Progress is printed by rank 0 and GPU device 0 only.

    Parameters:

    • slots Host-side particle slots.
    • slots_d Device-side particle slots (GPU only).
    • bkg Host-side background plasma.
    • bkg_d Device-side background plasma (GPU only).
    • imp_stats Host-side impurity statistics.
    • imp_stats_d Device-side impurity statistics (GPU only).
    • oa_ioniz Host-side OpenADAS ionization rate coefficients.
    • oa_ioniz_d Device-side OpenADAS ionization rate coefficients (GPU only).
    • oa_recomb Host-side OpenADAS recombination rate coefficients.
    • oa_recomb_d Device-side OpenADAS recombination rate coefficients (GPU only).
    • opts Simulation options.
    • opts_d Device-side simulation options (GPU only).
    • timer Timer that accumulates the time spent in each step.
    • ioniz_warnings Counter of particles whose ionization probability exceeded 1.
    • recomb_warnings Counter of particles whose recombination probability exceeded 1.
    • rngs Host-side random number generators, one per OpenMP thread (CPU only).
    • rngs_d Device-side random number generators (GPU only).
    • max_time_ctr Counter of particles that exceeded the maximum allowed time.

    Advances every alive particle in slots by one time step (CPU implementation).

    Each alive particle's time since launch (pt) and background time (t) are increased by dt, and its x, y and z positions are advanced using its current velocity. If the particle's time since launch exceeds the imp_max_time option, the particle is marked dead and max_time_ctr is incremented. The iteration counter of each stepped particle is also incremented. Dead particles are skipped. The loop over particles is parallelized with OpenMP.

    Parameters:

    • slots Particle slots to advance.
    • bkg Background plasma (currently unused).
    • opts Simulation options, used for imp_max_time.
    • dt Time step (s).
    • max_time_ctr Counter of particles that exceeded the maximum allowed time. Incremented atomically.
