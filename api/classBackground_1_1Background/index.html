    function broadcast

    void Background::Background::broadcast (
    MPI_Comm comm
)

    Broadcasts the background from rank 0 to every other MPI rank.

    Every rank must call this. After it returns, every rank holds a copy of the dimensions, the simulation bounds (t, x, y and z min/max), the times and computational grid, the geometry data and the plasma and field data loaded on rank 0. Not broadcast are bR, the covariant magnetic field components (b_x, b_y, b_z) and the electric field gradient (gradeX, gradeY, gradeZ), which are only saved to the output file on rank 0.

    Parameters:

    • comm MPI communicator to broadcast over.

    function check_dim

    std::string Background::Background::check_dim (
    const int m_dim,
    const int in_dim,
    const int dim_num
)

    Checks that a new dimension matches the dimension already stored.

    A stored dimension of 0 means it has not been set yet, so any new dimension is accepted. Otherwise the two must be equal.

    Parameters:

    • m_dim Dimension currently stored in the Background.
    • in_dim Dimension of the data being loaded.
    • dim_num Which dimension (1-4) is being checked (for the message).

    Returns:

    Empty if the dimensions are consistent. Otherwise a line describing the mismatch, for set_dims to put in its error message.

    function set_dims

    template<typename T>
void Background::Background::set_dims (
    Vectors::Vector4D < T > & v,
    const std::string_view data
)

    Checks the dimensions of a Vector4D against the stored dimensions and stores them if they are consistent.

    Each of the four dimensions of v is checked with check_dim. If all four are consistent, they become the stored dimensions. If any are not, the run is stopped with Errors::fatal_error, listing every dimension that doesn't match. A mismatch means the data is not being read in correctly or is from different Gkeyll runs.

    Template parameters:

    • T Data type stored in the Vector4D.

    Parameters:

    • v Vector4D whose dimensions are checked.
    • data Name of the data being loaded (for the error message).

    function to_device

    BackgroundDevice Background::Background::to_device (
    int device_id=0
)

    Copies the background to a GPU.

    The times, cell centers, cell edges and simulation bounds are copied to constant memory (see device_constants.cu), and the 3D and 4D arrays are allocated and copied to global memory. Constant memory is per GPU, so each GPU gets its own copy. Constant memory is shared by everything on a GPU, though, so only one background can be on each GPU at a time. Copying a second one to the same GPU overwrites the constant memory of the first.

    Stops the run with Errors::fatal_error if a dimension is too big for the constant memory arrays (see MAX_1D in device_constants.cuh).

    Parameters:

    • device_id ID of the GPU to copy to.

    Returns:

    The device-side background. Its pointers are to global memory on the GPU and must be freed with free_bkg.
