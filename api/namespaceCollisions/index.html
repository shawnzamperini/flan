    function collision_gpu

    void Collisions::collision_gpu (
    Slots::SlotsDevice & slots_d,
    const Background::BackgroundDevice & bkg_d,
    const bool elec,
    const double dt,
    ImpurityStats::StatisticsDevice & imp_stats_d,
    pcg32 * rngs_d,
    const double elec_mass_amu,
    const double ion_mass_amu,
    const Options::OptionsDevice * opts_d
)

    Launches nanbu_coll_kernel to update the velocity of every particle on the GPU due to collisions with one background species.

    Uses blocks of 256 threads, one thread per slot. The launch is asynchronous, except in DEBUG builds, where it waits for the kernel to finish and prints any error.

    Parameters:

    • slots_d Particle slots on the device.
    • bkg_d Background plasma on the device.
    • elec If true, collide with electrons. Otherwise collide with ions.
    • dt Time step (s).
    • imp_stats_d Impurity statistics on the device.
    • rngs_d Random number generators on the device, one per slot.
    • elec_mass_amu Electron mass (amu).
    • ion_mass_amu Main ion mass (amu).
    • opts_d Simulation options on the device.

    function nanbu_calc_A

    double Collisions::nanbu_calc_A (
    const double s
)

    Calculates the A term in the Nanbu collision model (Eq. 13), which sets the shape of the distribution the deflection angle is sampled from.

    For s < 0.01 (weakly collisional) A = 1 / s, and for s > 5 (strongly collisional) A = 3 exp(-s). In between, A is linearly interpolated from the precomputed table in nanbu_s_a.h, which was calculated using python/calc_nanbu.py.

    Parameters:

    • s The s term from nanbu_calc_s.

    Returns:

    The A term.

    function nanbu_calc_chi

    double Collisions::nanbu_calc_chi (
    const double s,
    const double A,
    pcg32 & rng
)

    Samples the deflection angle chi in the Nanbu collision model (Eq. 17).

    cos(chi) is found by directly inverting the cumulative distribution built from A, using a uniform random number U. For s < 0.02 the small-s limit 1 + s ln(U) is used, and for s > 6 the deflection is isotropic, 2U - 1. cos(chi) is clamped to [-1, 1] to guard against rounding errors.

    Parameters:

    • s The s term from nanbu_calc_s.
    • A The A term from nanbu_calc_A.
    • rng Random number generator for this thread.

    Returns:

    Deflection angle chi (radians).

    function nanbu_calc_s

    std::tuple< double, double, double, double > Collisions::nanbu_calc_s (
    const Background::Background & bkg,
    const double imp_time_step,
    const double T,
    const double mass_kg,
    const double Te,
    const double ne,
    const double t,
    const double x,
    const double y,
    const double z,
    const double vX,
    const double vY,
    const double vZ,
    const int q,
    Slots::Slots & slots,
    pcg32 & rng
)

    Calculates the s term in the Nanbu collision model (Eq. 19), which measures how collisional this time step is.

    The relative velocity g is between the impurity and a background particle whose velocity is sampled from a drifting Maxwellian (flow plus thermal sampling) with sample_bkg_velocity. The Coulomb logarithm uses the Debye length and the expectation value of the impact parameter b0, and is clamped to be at least 1. The background species is assumed to be singly charged with ni = ne. An error is printed if the Coulomb logarithm or s is NaN.

    Parameters:

    • bkg Background plasma, used to interpolate the flow velocity.
    • imp_time_step Time step (s).
    • T Temperature of the background species colliding with the impurity (eV).
    • mass_kg Mass of the background species (kg).
    • Te Electron temperature (eV), used for the Debye length.
    • ne Electron density (m^-3).
    • t Time of the particle (s).
    • x Computational x coordinate of the particle.
    • y Computational y coordinate of the particle.
    • z Computational z coordinate of the particle.
    • vX Cartesian X velocity of the impurity (m/s).
    • vY Cartesian Y velocity of the impurity (m/s).
    • vZ Cartesian Z velocity of the impurity (m/s).
    • q Charge state of the impurity. Must not be 0.
    • slots Particle slots, used for the impurity mass.
    • rng Random number generator for this thread.

    Returns:

    {s, gX, gY, gZ}, where gX, gY and gZ are the Cartesian components of the relative velocity (m/s).

    function nanbu_coll

    void Collisions::nanbu_coll (
    Slots::Slots & slots,
    const Background::Background & bkg,
    const Options::Options & opts,
    bool elec,
    const double dt,
    Impurity::Statistics & imp_stats,
    std::vector< pcg32 > & rngs
)

    Updates the Cartesian velocity of every particle due to Coulomb collisions with one background species using the Nanbu model.

    Dead and neutral particles are skipped. For each particle, ne and Te (and Ti for ions) are interpolated at the particle location, then s, A and chi are calculated and the velocity is updated with nanbu_post_coll. Since this happens after the Boris update, the updated velocity is v at n+1/2. An error is printed if ne < 0 or chi is NaN.

    For ion collisions, s * weight * dt is also added to imp_stats so the average s in each cell can be calculated later.

    Parameters:

    • slots Particle slots. The velocities are updated in place.
    • bkg Background plasma.
    • opts Simulation options, used for the background masses (gkyl_elec_mass_amu, gkyl_ion_mass_amu) and min_ti.
    • elec If true, collide with electrons (Te). Otherwise collide with ions (Ti, limited to at least min_ti).
    • dt Time step (s).
    • imp_stats Impurity statistics, where the s values are summed for ion collisions.
    • rngs Random number generators, one per OpenMP thread.

    function nanbu_coll_kernel

    void Collisions::nanbu_coll_kernel (
    Slots::SlotsDevice slots_d,
    const Background::BackgroundDevice bkg_d,
    bool elec,
    const double dt,
    ImpurityStats::StatisticsDevice stats_d,
    pcg32 * rngs_d,
    const double elec_mass_amu,
    const double ion_mass_amu,
    const Options::OptionsDevice * opts_d
)

    Kernel that updates the Cartesian velocity of each particle due to Coulomb collisions with one background species using the Nanbu model.

    One thread handles one slot, and dead particles are skipped. ne, Te (and Ti for ions) are interpolated at the particle location and held at or above min_ne, min_te and min_ti. Then s, A and chi are calculated and the velocity is updated with nanbu_post_coll_cuda. Since this happens after the Boris update, the updated velocity is v at n+1/2. A message is printed if chi is NaN.

    Parameters:

    • slots_d Particle slots on the device. The velocities are updated in place.
    • bkg_d Background plasma on the device.
    • elec If true, collide with electrons (Te). Otherwise collide with ions (Ti).
    • dt Time step (s).
    • stats_d Impurity statistics on the device. Currently unused, since recording s is commented out.
    • rngs_d Random number generators on the device, one per slot.
    • elec_mass_amu Electron mass (amu).
    • ion_mass_amu Main ion mass (amu).
    • opts_d Simulation options on the device, used for min_ne, min_te and min_ti.

    function nanbu_post_coll

    std::tuple< double, double, double > Collisions::nanbu_post_coll (
    const double gX,
    const double gY,
    const double gZ,
    const double chi,
    const double mass_a,
    const double mass_b,
    const double vX,
    const double vY,
    const double vZ,
    pcg32 & rng
)

    Calculates the post-collision Cartesian velocity of the impurity in the Nanbu collision model (Eq. 20a).

    The relative velocity g is rotated by the deflection angle chi about a random azimuthal angle, uniformly distributed in [0, 2 pi). The case where g is parallel to X is handled separately to avoid dividing by zero.

    Parameters:

    • gX Cartesian X component of the relative velocity (m/s).
    • gY Cartesian Y component of the relative velocity (m/s).
    • gZ Cartesian Z component of the relative velocity (m/s).
    • chi Deflection angle from nanbu_calc_chi (radians).
    • mass_a Mass of the impurity (kg).
    • mass_b Mass of the background species (kg).
    • vX Cartesian X velocity of the impurity before the collision (m/s).
    • vY Cartesian Y velocity of the impurity before the collision (m/s).
    • vZ Cartesian Z velocity of the impurity before the collision (m/s).
    • rng Random number generator for this thread.

    Returns:

    Post-collision velocity {vX, vY, vZ} in Cartesian space (m/s).

    function sample_bkg_velocity

    std::tuple< double, double, double > Collisions::sample_bkg_velocity (
    const double T,
    const double uX,
    const double uY,
    const double uZ,
    const double m,
    pcg32 & rng
)

    Samples the velocity of a background particle from a drifting Maxwellian.

    Each component is drawn from a normal distribution with a mean equal to the flow velocity and a standard deviation of sqrt(kT/m). We call this thermal sampling of the background velocity.

    Parameters:

    • T Temperature of the background species (eV).
    • uX Cartesian X flow velocity of the background species (m/s).
    • uY Cartesian Y flow velocity of the background species (m/s).
    • uZ Cartesian Z flow velocity of the background species (m/s).
    • m Mass of the background species (kg).
    • rng Random number generator for this thread.

    Returns:

    Sampled velocity {vX, vY, vZ} in Cartesian space (m/s).
