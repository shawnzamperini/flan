    t: Time of the particle x,y,z: Coordinates of the particle in computational space X,Y,Z: Coordinates of the particle in Cartesian space vX,vY,vZ: Velocity components of the particle in Cartesian space weight: The Monte Carlo weight of the particle q: Current charge of the particle Z: Atomic number mass: The mass of the particle (kg)

    function Slots

    explicit Slots::Slots::Slots (
    int N
)

    Creates a Slots object with room for N particles.

    Every per-particle vector is resized to N. The values are zero initialized, so every slot starts with state 0 (alive). The mass and atomic number are not set here, use set_mass and set_Z.

    Parameters:

    • N Number of particle slots.

    function to_device

    SlotsDevice Slots::Slots::to_device (
    int device_id=0
)

    Allocates GPU memory for the particles and copies them to the device.

    I think this should probably be moved to slots.cu...

    The per-particle arrays are allocated and copied, except pt and iters, which are not stored on the device. The work arrays used by the GPU kernels (all_dead, counter, alive, num_dead and dead_indices) are also allocated, and all_dead is initialized to false. If GPU support was not compiled in, an error is printed and an empty SlotsDevice is returned.

    Parameters:

    • device_id ID of the GPU to allocate the memory on.

    Returns:

    SlotsDevice struct holding the device pointers. The memory must be released with free_slots.

    function to_host

    Slots Slots::Slots::to_host (
    const SlotsDevice & slots_d
)

    Copies the particles from the device back into a new host Slots object.

    The mass and the per-particle arrays on the device are copied back. pt, iters and the atomic number are not stored on the device, so they are left at zero in the returned object. The device memory is not freed, use free_slots for that. If GPU support was not compiled in, only N and the mass are set.

    Parameters:

    • slots_d SlotsDevice struct returned by to_device.

    Returns:

    Host Slots object holding a copy of the device data.
