    function fill_slots_cpu

    void Slots::fill_slots_cpu (
    Slots & slots,
    int & rem_parts,
    int & alive_slots,
    const Background::Background & bkg,
    const Options::Options & opts,
    std::vector< pcg32 > & rngs
)

    Replaces dead particles with new ones, as long as there are particles remaining to be followed.

    The dead slots are counted first. The number refilled is the smaller of the dead count and rem_parts, and rem_parts is reduced by that number. Each refilled slot gets a new particle from make_new_particle, using the random number generator of the thread doing the work, with its particle time reset to 0 and its state set to alive.

    Parameters:

    • slots Particle slots to refill.
    • rem_parts Number of particles still to be followed. Reduced by the number of particles created, and never goes below 0.
    • alive_slots Set to the number of alive slots after refilling.
    • bkg Background plasma.
    • opts Simulation options.
    • rngs Random number generators, one per OpenMP thread.

    void Slots::free_slots (
    SlotsDevice & slots_d,
    int device_id
)

    Frees the GPU memory held by a SlotsDevice struct.

    Every device array allocated in Slots::to_device is freed. The particle array pointers and all_dead are then set to nullptr. Does nothing if GPU support was not compiled in.

    Parameters:

    • slots_d SlotsDevice struct whose memory is freed.
    • device_id ID of the GPU the memory was allocated on.

    function get_birth_vXYZ

    std::array< double, 3 > Slots::get_birth_vXYZ (
    const Background::Background & bkg,
    const Options::Options & opts,
    const double t,
    const double x,
    const double y,
    const double z,
    const int tidx,
    const int xidx,
    const int yidx,
    const int zidx,
    pcg32 & rng
)

    Picks the starting Cartesian velocity of a new particle.

    For the test backgrounds (bkg_source = "test") the velocity is fixed by the test case: 10,000 m/s in Y for the gyrate, ExB, grad-B and polarization tests, 30,000 m/s along the field line (in the X-Y plane, at angle z) for the curvature test, and at rest for the friction test.

    Otherwise each component is sampled from a Maxwellian with zero mean and sigma = sqrt(kT/m), giving an isotropic velocity distribution. The temperature is imp_temp_start_val if imp_temp_start_opt is "single_value", or the main ion temperature in the particle's cell if it is "ti". The ion temperature is the cell value, not interpolated.

    Parameters:

    • bkg Background plasma, used for the ion temperature.
    • opts Simulation options.
    • t Starting time of the particle (s). Currently unused.
    • x Starting computational x coordinate. Currently unused.
    • y Starting computational y coordinate. Currently unused.
    • z Starting computational z coordinate. Only used by the curvature test, where z is the toroidal angle.
    • tidx Index of the nearest background time frame.
    • xidx x index of the grid cell containing the particle.
    • yidx y index of the grid cell containing the particle.
    • zidx z index of the grid cell containing the particle.
    • rng Random number generator for this thread.

    Returns:

    Starting velocity {vX, vY, vZ} in Cartesian space (m/s).

    function get_birth_val

    double Slots::get_birth_val (
    const int start_opt_int,
    const double start_val,
    const double range_min,
    const double range_max,
    const double bkg_min,
    const double bkg_max,
    pcg32 & rng
)

    Picks the starting value of t, x, y or z for a new particle based on the input options.

    The same function is used for each coordinate, with the matching imp_*start_opt option deciding where the particle starts: 0: At start_val. 1: Uniformly random between range_min and range_max. 2: Uniformly random over the full simulation volume, between bkg_min and bkg_max. Any other value returns 0.

    Parameters:

    • start_opt_int Control integer of the imp_*start_opt option.
    • start_val Starting value used when start_opt_int is 0.
    • range_min Lower end of the range used when start_opt_int is 1.
    • range_max Upper end of the range used when start_opt_int is 1.
    • bkg_min Minimum of the simulation volume, used when start_opt_int is 2.
    • bkg_max Maximum of the simulation volume, used when start_opt_int is 2.
    • rng Random number generator for this thread.

    Returns:

    Starting value of the coordinate.

    function make_new_particle

    ParticleInit Slots::make_new_particle (
    const Background::Background & bkg,
    const Options::Options & opts,
    pcg32 & rng
)

    Creates a new particle at its starting time, location and velocity.

    The starting t, x, y and z come from get_birth_val using the imp_*start_opt options. The time index and grid cell indices are then found, the same as in impurity_transport.cpp, and the Cartesian velocity comes from get_birth_vXYZ. The computational velocity is set to zero, since it gets set on the first call to Boris::update_velocity. The weight is 1 / imp_num and the charge is imp_init_charge.

    Parameters:

    • bkg Background plasma.
    • opts Simulation options.
    • rng Random number generator for this thread.

    Returns:

    The new particle.
