    Detailed Description

    Default values for every option are included in the definitions of each member variable. These can then be overwritten as in load_options.cpp

    function Options

    Options::Options::Options ()

    Constructs an Options object with every option at its default value.

    The defaults are set where each member variable is declared in options.h. The control integers are then set to match the default string options by calling initialize_control_ints.

    int Options::Options::bkg_source_int () const

    Returns the control integer for the bkg_source option.

    function get_control_int

    int Options::Options::get_control_int (
    const std::string & var_name,
    const int control_int
) const

    Returns a control integer after checking that it was set.

    Control integers start at -1, meaning not set. If control_int is still negative, an error is printed. This usually means the option's setter is missing from initialize_control_ints. The value is returned either way.

    Parameters:

    • var_name Name of the option the control integer belongs to (for the error message).
    • control_int Control integer to check.

    Returns:

    The control integer, unchanged.

    function initialize_control_ints

    void Options::Options::initialize_control_ints ()

    Sets every control integer to match its string option.

    Control integers are integer versions of string options that are faster to check in the code than comparing strings. The logic that assigns each one lives in the option's setter, so this calls every such setter with the option's current value. Any new option with a control integer must have its setter called here too. Otherwise its control integer stays at -1, which get_control_int reports as an error.
