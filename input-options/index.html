    Input Options

    Input options are set in your input file through the inpts map, e.g.:

    inpts["case_name"] = "my_case";
inpts["imp_num"] = 10000;
inpts["imp_mass_amu"] = 183.84;

    Any option you don't set uses the default value listed below. The options are grouped by what they control.
